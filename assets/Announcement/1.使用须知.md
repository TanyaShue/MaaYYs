# 🚀使用须知

0. **使用该软件后被鬼使黑了概不负责！！！**

1. **下载与更新**：  
   - [GitHub Releases](https://github.com/TanyaShue/MaaYYs/releases/)  
   - [mirror酱](https://mirrorchyan.com/zh/projects?source=maafw-badge&rid=MaaYYs&os)  

2. **运行环境**：目前仅支持通过安卓模拟器或 macOS PlayCover 运行。Windows 和 Linux 请使用已开启 ADB 调试的安卓模拟器；不支持直接在 Windows/macOS/Linux 桌面端运行游戏。
   - **macOS**：支持使用 Apple Silicon Mac 搭配支持 MaaTools 的 PlayCover 运行 iOS 版阴阳师。请在 PlayCover 中启用 MaaTools，并在 MXU 中选择 `PlayCover` 控制器；普通 PlayCover 连接不受支持。
   - PlayCover 的安装与配置可参考 [MAA 官方中文 macOS 使用手册](https://docs.maa.plus/zh-cn/manual/device/macos.html)。
3. **设置**：安卓模拟器分辨率设为 **16:9**；PlayCover 请保持横屏。
4. **语言**：目前仅支持简体中文，若有其他语言需求欢迎加入开发。
