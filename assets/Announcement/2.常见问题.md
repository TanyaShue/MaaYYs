# ❓ 常见问题

## 🔑 通用问题

### Q：启动提示"资源加载失败"？

✅ 解决方案：  

1. 删除安装目录下除 `config` 外所有文件夹  
2. 重新解压最新版到原目录  
3. 重启软件  

## Q：我下载的模拟器是官网下的专版（或桌面端）可以用吗

❌️ 用不了，欢迎加入开发，因为这说是模拟器实际上是桌面端，需额外适配

## Q: 如何让脚本自行自动模拟器

    1. 在软件下放点击添加任务-特殊任务-前置程序
    2. 填入模拟器路径，其中附加参数为所需模拟器序号的n-1(例如你是mumu模拟器第二台，那参数就是-v 1)  
    3. 推荐再加一个倒计时
    4. 若有多开其他脚本的需求可前往[AUTO_MAS](https://doc.auto-mas.top/docs)

### Q：连接后无响应？

✅ 检查清单：  

- 模拟器分辨率设为16:9  
- 重启模拟器 + 软件  
- 软件内执行"连接测试"  
- 优先使用MuMu/雷电模拟器  

## 🛠️ 技术支持

### Q：如何导出有效日志？

✅ 黄金流程：  

1. 删除 `debug` 文件夹  
2. 复现问题  
3. 点击软件内 **|→** 按钮导出日志  
4. 连同截图提交至[问题反馈](3.问题反馈.md)  

### Q：双击无法启动，命令行可运行？

✅ Windows安全策略解除：  
右键 `MXU.exe` → 属性 → 勾选"解除锁定" → 应用
